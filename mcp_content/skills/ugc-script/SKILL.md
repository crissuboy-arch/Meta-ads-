# UGC Script (User Generated Content)

UGC works because it doesn't sound like an ad. Every script must read as if a real person were talking to another real person, with pauses, informality, and natural imperfection — never like a memorized sales script.

## Script structure (30-60 seconds, adjustable)

1. **Hook (0-3s)**: use the `creative-hooks` skill; the "personal confession" or "immediate identification" pattern works best in UGC.
2. **Context/identification (3-10s)**: the person identifies with the problem — "I also [situation]" — without mentioning the product yet.
3. **The turn (10-20s)**: how they discovered the product/solution — discovery tone, not advertising ("I saw an ad and almost didn't click, but...").
4. **Proof/real use (20-40s)**: what changed, in a specific and believable way — avoid exaggeration ("it changed my life" with no context sounds fake; "I can do X now, which I couldn't before" is more believable).
5. **Objection handling (40-50s)**: anticipate the niche's most common doubt (price, does it really work, is it complicated) and answer in a conversational tone, not a sales argument.
6. **CTA (final seconds)**: direct, casual invitation, not an ad command ("I left the link right here" sounds more real than "click now and get yours").

## Non-negotiable rules

- **Nothing invented**: every result, number, or testimonial cited must come from the user/the product's real data — if there's no real data, write generically without fabricated numbers.
- **No advertising language** ("revolutionary," "never seen before," "guaranteed") — it breaks the authentic-UGC illusion and raises the risk of Meta policy rejection.
- **Natural-speech markers**: include bracketed cues like `[pause]`, `[laughs]`, `[looks at the product]` to guide whoever records it.

## Output

Deliver the full script line by line with approximate timing marks, plus a clean version with only the spoken lines, ready to read. If the user asks for more than one variation, change the entry angle (pain vs. desire vs. initial skepticism) while keeping the same 6-part structure.
